# ⚡ Milijon — ورکر پروکسی پایتون (دیپلوی خودکار و Zero-Config در Railway)

**Milijon** یک ورکر پروکسی تمام‌پایتونی (Full-Python)، سبک و مدرن است که به گونه‌ای طراحی شده تا **بدون نیاز به حتی یک خط تنظیمات دستی (Zero-Config)** به محض اتصال مخزن گیت‌هاب به پلتفرم ابری **Railway** به صورت کاملاً خودکار و بدون دخالت دست، بیلد، اجرا و مستقر شود.

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app)

---

## 🎯 استقرار خودکار و بی‌دردسر (Zero-Touch Auto Deploy)

این پروژه طوری کدنویسی شده که برای اجرای اولیه به **هیچ متغیر محیطی اجباری (Zero ENV required)** نیاز ندارد:

1. **تشخیص خودکار پورت ریلوی:** متغیر داینامیک `$PORT` بدون نیاز به تنظیم، توسط هسته لینوکس و اسکریپت ران تایم شناسایی و Bind می‌شود.
2. **تشخیص خودکار دامنه (Auto Domain Detection):** آدرس سرور و دامنه (مثلاً `xxxx.up.railway.app` یا دامنه شخصی) به صورت کاملاً هوشمند از روی هدر درخواست‌های دریافتی استخراج شده و لینک‌های VLESS، Trojan و سابسکریپشن خودکار با همان دامنه ساخته می‌شوند.
3. **دیتابیس خودسازگار (Auto Database Setup):** در اولین استارت، فایل دیتابیس SQLite به همراه جدول کاربران و کاربر اولیه به صورت خودکار ساخته می‌شود.
4. **بررسی سلامت آنی (Fast Healthcheck):** اندپوینت `/health` بلافاصله وضعیت سبز `healthy` را به ریلوی ارسال می‌کند تا پروژه بدون انتظار وارد مدار شود.
5. **استقرار پیوسته (Continuous Deployment):** هر بار که در گیت‌هاب تغییری Commit و Push کنید، ریلوی به صورت خودکار پروژه را از نو بیلد کرده و بدون قطعی (Zero-Downtime) به‌روزرسانی می‌کند.

## 🚀 مراحل راه‌اندازی (تنها در ۳ مرحله ساده)

### مرحله ۱: پوش کردن کدها به گیت‌هاب
کدهای درون پوشه پروژه را در یک مخزن دلخواه در حساب گیت‌هاب خود قرار دهید:
```bash
git init
git add .
git commit -m "Deploy Milijon to Railway"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/milijon.git
git push -u origin main
```

### مرحله ۲: اتصال مخزن به ریلوی (بدون هیچ تنظیمی)
1. وارد [Railway.app](https://railway.app) شوید.
2. روی دکمه **New Project** کلیک کنید.
3. گزینه **Deploy from GitHub repo** را انتخاب کرده و مخزن `milijon` را انتخاب نمایید.
4. تمام! **هیچ تنظیمات، دستور یا متغیر محیطی نیاز نیست اضافه کنید.** ریلوی داکرفایل و فایل `railway.json` را خوانده و در کمتر از ۱ دقیقه پروژه را مستقر می‌کند.

### مرحله ۳: دریافت آدرس دامنه
1. در داشبورد ریلوی، وارد تب **Settings** پروژه خود شوید.
2. به بخش **Networking** رفته و روی دکمه **Generate Domain** کلیک کنید.
3. یک آدرس اختصاصی با گواهینامه معتبر HTTPS (مثل `milijon-production.up.railway.app`) دریافت می‌کنید.
4. آدرس را در مرورگر باز کنید و وارد پنل مدیریت شوید!

> **رمز عبور پیش‌فرض پنل مدیریت:** `milijon_admin`  
> *(در صورت تمایل، می‌توانید در بخش Variables ریلوی متغیر `ADMIN_PASSWORD` را به رمز دلخواه خود تغییر دهید).*

## 📱 نحوه دریافت کانفیگ و استفاده در گوشی و سیستم

1. در صفحه اول پنل ادمین، لیست کاربران نمایش داده شده است (کاربر اول `DefaultUser` به صورت پیش‌فرض آماده است).
2. برای هر کاربر می‌توانید:
   - **لینک VLESS:** مخصوص کلاینت‌های v2rayNG, v2rayN, MahsaNG, Streisand
   - **لینک Trojan:** پروتکل سریع و سبک
   - **لینک VMess:** پروتکل با رمزنگاری پیشرفته
   - **لینک سابسکریپشن خودکار (Subscription):** اضافه کردن مستقیم به نرم‌افزار جهت به‌روزرسانی خودکار
   - **کانفیگ Clash Meta / Mihomo:** خروجی اختصاصی YAML
   - **کانفیگ Sing-box:** خروجی اختصاصی JSON
   - **اسکن QR Code:** اسکن مستقیم با دوربین گوشی در نرم‌افزار

## 🛡️ بهینه‌سازی‌های دور زدن فیلترینگ منطقه‌ای

- 🇮🇷 **پکیج ایران:**
  - فعال‌سازی خودکار **TLS Fragment** (تکه‌تکه‌کردن پکت هلو با سایز `100-200` و تاخیر `10-20ms`) برای فرار از سیستم DPI همراه اول و ایرانسل.
  - فعال‌سازی **Early Data (`?ed=2048`)** جهت کاهش تأخیر پکت‌ها.
  - ادغام لیست آی‌پی‌های تمیز کلودفلر (Clean IP) برای زمان‌هایی که آی‌پی اصلی اپراتور مسدود شده باشد.
- 🇨🇳 **پکیج چین:** هدر استتاری ALPN روی `h2,http/1.1` جهت فرار از پروب‌های دیوار آتش چین (GFW).
- 🇷🇺 **پکیج روسیه:** استتار به عنوان ترافیک امن وب بدون امضاهای رایج پروتکل‌های مسدودشده در TSPU.

## 🌐 موتور جمع‌آوری و تست زنده نودهای عمومی (Public Node Harvester & Health Check)

به جای تکیه بر دامنه‌های ساختگی، یک سرویس پس‌زمینه خودکار پایتونی در Milijon تعبیه شده است:
1. **استخراج دوره‌ای از گیت‌هاب:** نودهای عمومی و پرسرعت جهان (آلمان، هلند، آمریکا، فنلاند، فرانسه و...) را از سورس‌های معتبر دریافت می‌کند.
2. **پایش سلامت و پینگ زنده TCP:** هندشیک سه‌مرحله‌ای TCP به ازای هر نود تست شده و پینگ دقیق میلی‌ثانیه‌ای اندازه‌گیری می‌شود.
3. **ذخیره‌سازی به همراه پرچم واقعی:** نودهای سالم و کم‌پینگ به همراه پرچم ایموجی کشور و کد جغرافیایی در دیتابیس SQLite ذخیره می‌شوند.
4. **تزریق خودکار به سابسکریپشن‌ها:**
   - **Clash Meta / Mihomo:** گروه‌های `⚡ Auto-Fastest (کم‌ترین پینگ)` مبتنی بر url-test و `🌐 World Nodes` با نودهای زنده ایجاد می‌شوند.
   - **Sing-box:** اوتباندهای تست‌شده به همراه انتخابگر خودکار `auto-fastest` قرار داده می‌شوند.
5. **متغیرهای محیطی قابل تنظیم:**
   - `HARVESTER_ENABLED`: فعال/غیرفعال‌سازی موتور (پیش‌فرض: `true`).
   - `HARVESTER_INTERVAL_MINUTES`: فاصله زمانی بررسی‌ها به دقیقه (پیش‌فرض: `30`).
   - `HARVESTER_MAX_PING`: حداکثر پینگ مجاز بر حسب میلی‌ثانیه (پیش‌فرض: `1500`).

## 📂 ساختار فایل‌های پروژه

```
milijon/
├── main.py                     # هسته اصلی وب‌سرور و روت‌های پنل
├── requirements.txt            # نیازمندی‌های پایتون
├── Dockerfile                  # داکرفایل سبک پایتون ۳.۱۱ اسلیم
├── railway.json                # فایل شناسایی و بیلد خودکار ریلوی
├── Procfile                    # فرمان استارت سرور
├── docker-compose.yml          # اجرای لوکال با داکر
├── .github/
│   └── workflows/
│       └── railway.yml         # اکشن اختیاری CI/CD گیت‌هاب
├── app/
│   ├── __init__.py
│   ├── config.py               # تنظیمات و مقادیر پیش‌فرض
│   ├── database.py             # دیتابیس SQLite و جدول نودهای عمومی
│   ├── harvester.py            # موتور جمع‌آوری و تست زنده پینگ نودها
│   ├── proxy_engine.py         # هندلر وب‌سوکت VLESS و Trojan
│   ├── generator.py            # تولید کانفیگ با ادغام نودهای عمومی
│   └── templates/
│       └── index.html          # داشبورد شیشه‌ای با مانیتورینگ نودها
└── README.md                   # مستندات پروژه
```
